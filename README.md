# 📖 About The Project

**CyberChess** reimagines the traditional chess experience by introducing AI-powered gesture controls.

Instead of using a traditional mouse or keyboard, players can control chess pieces using real-time hand gestures captured through their webcam.

The application uses **MediaPipe Hand Tracking** to detect hand landmarks and convert finger movements into chess interactions.

This project demonstrates the combination of:

- 🤖 Artificial Intelligence
- 👁️ Computer Vision
- 🎮 Game Development
- 🌐 Web Technologies
- 🧠 Human Computer Interaction

# 🎮 How To Play


| Action | Gesture |
|---|---|
| 🖐 Select Piece | Point index finger at a chess piece |
| 🎯 Select Destination | Move finger to target square |
| ♟ Execute Move | Hold position to confirm movement |
| ⏸ Interface Controls | Hover over buttons |


### 💡 Gameplay Tips

✔ Keep your hand visible to the webcam  
✔ Maintain proper lighting conditions  
✔ Move slowly for better accuracy  
✔ Keep the camera stable

# ⚙️ Installation & Setup


## 1️⃣ Clone Repository


```bash
git clone https://github.com/swapnil88477-hub/Chess.git
```


## 2️⃣ Navigate Into Project


```bash
cd Chess
```


## 3️⃣ Run Application


CyberChess is a frontend-based web application.

No backend server configuration is required.


### Recommended Method:

Install the **Live Server Extension** in VS Code.

Then:

```
Right Click on index.html
        ↓
Open With Live Server
```


The application will open automatically in your browser.


### Dependency Note:

`package.json` and `requirements.txt` are included for project organization and dependency tracking.

They are not required to run the browser version when required libraries are loaded through CDN.
